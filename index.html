Installation & First Launch

Get DataCleaner up and running in under a minute.

1

Download the Installer

Download DataCleaner.exe from the latest release on GitHub. The download is approximately 80 MB and contains everything you need to run the application with no additional dependencies required.

2

Run the Executable

Double-click the downloaded executable to launch DataCleaner. No installation wizard is required — DataCleaner runs as a portable application. Windows SmartScreen may prompt you on first launch; click "More info" then "Run anyway" to proceed.

3

Onboarding Tour

On first launch, an interactive onboarding spotlight tour will guide you through the main interface. This tour highlights the toolbar, workflow tabs, data preview area, and bottom panel. You can revisit the tour at any time from the Help menu.

4

Import Your First File

Drag and drop a CSV or Excel file onto the application window, or press Ctrl+O to open the file browser. DataCleaner will automatically detect the file encoding, delimiter, and column data types and display a preview of your data.

Main Interface Overview

DataCleaner uses a modern, Apple-inspired interface with a clear left-to-right workflow. Every panel serves a specific purpose in the data cleaning pipeline.

Workflow Tabs (Left)

Navigate through each step of the cleaning pipeline from top to bottom. The active tab is highlighted in blue. Each tab contains all the controls and options for that particular step.

Data Preview (Center)

Displays up to 200 rows of your data in a sortable, scrollable table. Cells with potential issues (null tokens, invalid dates, European numbers) are highlighted in red for easy identification.

Column Statistics (Right)

Click any column header to view detailed statistics including data type, null count, unique values, min/max, and a completeness progress bar. Invaluable for understanding data quality at a glance.

Output Panel (Bottom)

Toggle with Shift+`. Three tabs show operation logs (Output), import/processing warnings (Warnings), and a summary of all modifications made (Changes).

Toolbar

Quick-access buttons for file operations (Open, Save), undo/redo, profile selection, and the Quality Dashboard. All toolbar actions have corresponding keyboard shortcuts for power users.

Status Bar

Always-visible bar at the bottom showing current row count, column count, file size, memory usage, and the last operation performed. Provides instant feedback on the state of your data.

Automatic Detection

When you import a file, DataCleaner performs the following automatic detection steps to ensure your data is read correctly:

  • •Encoding Detection: Automatically identifies the character encoding of your file. Supports UTF-8 (with and without BOM), Windows-1252, Latin-1, ASCII, and many others. If detection fails, you can manually specify the encoding from a dropdown menu.
  • •Delimiter Detection: Analyzes the first several rows of your file to determine the field separator. Supports comma (,), semicolon (;), tab (\t), and pipe (|). European CSV files that use semicolons are detected automatically.
  • •Data Type Inference: Each column is analyzed to determine its data type (string, integer, float, date, boolean). The confidence threshold is 85% by default, meaning at least 85% of the non-null values in a column must match a type for it to be assigned. This threshold is configurable in your cleaning profile.
  • •Header Detection: The first row is checked for potential column headers. If no headers are detected, generic column names (Column_1, Column_2, etc.) are assigned automatically.

2

Clean

Ctrl+2 / F5

The Clean tab is where the bulk of your data transformation happens. Each transformation can be toggled independently, giving you full control over which operations are applied to your dataset.

T Whitespace Trimming

Removes leading and trailing whitespace characters from every cell value in your dataset. This is one of the most common data quality issues, especially when data is exported from legacy systems or manually entered.

Characters removed include: spaces, tabs (\t), newlines (\n), carriage returns (\r), and other Unicode whitespace characters. This operation does not affect whitespace within a value (e.g., "John Smith" remains unchanged).

Before: "  Alice Johnson  "
After: "Alice Johnson"

E Empty Row Removal

Removes rows where every single column value is null, empty, or contains only whitespace. A row is only removed if all columns in that row are empty — rows with even a single non-empty value are preserved. This is useful for cleaning up files that have blank rows inserted as separators or padding.

N Null Token Normalization

Converts over 46 different textual representations of "nothing" into actual null values. Many systems export empty values as text strings like "N/A", "null", or "-", which can cause problems in analysis. This transformation normalizes all of these to proper nulls.

The following tokens are recognized by default (case-insensitive matching is used for most):

NULL null Null NONE none None N/A NA n/a na NaN NAN nan - -- --- . .. #N/A #NA #VALUE! undefined "" ...

You can customize the list of null tokens in your cleaning profile. See the Profiles section for details.

H Header Normalization

Standardizes column header names for consistency and compatibility with downstream systems like databases and analytics tools. Each sub-option can be toggled independently.

OptionDescriptionExample
Trim whitespaceRemoves leading/trailing spaces from column names" First Name " → "First Name"
Convert to lowercaseConverts all header characters to lowercase"First Name" → "first name"
Replace spacesReplaces spaces with underscores (configurable separator)"first name" → "first_name"
Remove illegal charactersStrips characters not allowed in most systems: /\:*?"<>|\n\r\t"name/id" → "nameid"
Deduplicate namesAppends _2, _3, etc. to duplicate column names"name", "name" → "name", "name_2"

Auto Format

Ctrl+3

The Auto Format tab provides intelligent number and date normalization with per-column control. This is particularly important when working with data from different regional formats.

Numeric Normalization

Converts numbers from various regional formats into a standard format suitable for analysis. This is especially useful when working with European-formatted data where commas and periods have opposite meanings compared to US/UK conventions.

Input (Regional)Output (Standard)Format Detected
1.234,561234.56European (period=thousands, comma=decimal)
1,234.561234.56US/UK (comma=thousands, period=decimal)
1 234,561234.56French/Swiss (space=thousands, comma=decimal)
1,000,0001000000US/UK thousands separator removal
Ambiguity handling: When DataCleaner cannot determine with at least 90% confidence whether a value like 1,234 is one thousand two hundred thirty-four or the decimal number 1.234, it preserves the original value as text rather than risking an incorrect conversion. The ambiguity threshold is configurable (default: 90%).

Date Normalization

Converts dates from 16+ input formats into the ISO 8601 standard format (YYYY-MM-DD). This ensures consistency across your dataset and compatibility with databases and analytics tools.

MM/DD/YYYY03/15/20242024-03-15

DataCleaner uses day-first detection to distinguish between DD/MM and MM/DD formats. The confidence threshold is 90% by default. Ambiguous dates are preserved as text to prevent incorrect conversions.

Deduplicate

Ctrl+5 / F4

The Deduplicate tab helps you identify and remove duplicate records from your dataset. You can match on all columns or specify key columns, and choose which duplicate to keep.

Exact Deduplication

Finds rows that are identical across all selected columns. You can either compare all columns (whole-row duplicates) or specify specific key columns like email address or ID number to detect records that refer to the same entity.

Keep Strategies

Keep First

Keeps the first occurrence of each duplicate group and removes the rest. This is the default strategy and is appropriate when your data is ordered chronologically with the oldest records first.

Keep Last

Keeps the last occurrence of each duplicate group. Use this when your data has the most recent or most updated records at the bottom of the file.

Keep Most Complete

Keeps the row with the fewest null values. This is the best strategy when duplicates may have different levels of completeness and you want to preserve the most information.

Premium

Fuzzy Deduplication

For records that are similar but not identical (e.g., "Jon Smith" vs "John Smith"), fuzzy deduplication uses approximate string matching algorithms to find near-duplicates. This is available in Personal, Business, and Enterprise license tiers.

SettingValueDescription
AlgorithmLevenshtein distanceMeasures the minimum number of single-character edits needed to transform one string into another
Default threshold85%Pairs with 85% or higher similarity are flagged as duplicates
Minimum threshold50%The lowest threshold you can set (very aggressive matching)
Maximum threshold100%Equivalent to exact matching

Profiles & Templates

Save your cleaning settings as reusable profiles so you can apply the same configuration to new files with one click. Share profiles with your team for consistent data processing across your organization.

Bundled Profiles

DataCleaner ships with three pre-configured profiles designed for common use cases:

Default General

Conservative settings suitable for most files. Trims whitespace, normalizes nulls, and cleans headers. Safe to use as a starting point.

Bank Export

Optimized for financial data with strict numeric handling. Handles European decimal formats and ensures amounts are properly converted.

CRM Export

Designed for contact data with email validation rules pre-configured. Includes header normalization for common CRM column names.

Profile Storage

Profiles are saved as JSON files in your local application data directory:

%LOCALAPPDATA%\DataCleaner\profiles\

You can export profiles to share with teammates, import profiles from colleagues, and set a default profile that is automatically applied to new files. Profile management is available both in the GUI (Profiles tab) and via the CLI (datacleaner profile command).

Workflow Templates

Workflow templates combine a cleaning profile with export settings and SQL table definitions into a single reusable package. When you apply a template, it configures everything from import through export in one step. Templates are especially powerful when combined with folder watching — you can set up a watched folder that automatically applies a complete workflow to any file dropped into it.

Command-Line Interface

DataCleaner includes a full-featured CLI built with Python Click. Every operation available in the GUI can also be performed from the command line, making it perfect for scripting, automation, CI/CD pipelines, and batch processing.

Basic Usage
# Show version
datacleaner --version

# Show help for all commands
datacleaner --help

# Launch GUI mode explicitly
datacleaner --gui

# Available commands: info, clean, dedupe, validate, export, profile, batch, watch

datacleaner info

Display file statistics and column profiles without modifying the file. Use this to understand your data before running any cleaning operations.

OptionDescription
--jsonOutput results in JSON format for programmatic consumption
--profileInclude detailed column statistics: detected type, null count, unique count, top 10 values
--quiet, -qMinimal output showing only essential statistics
 
# Basic file info
datacleaner info data.csv

# Detailed column profiling in JSON
datacleaner info data.xlsx --json --profile

# Quick stats only
datacleaner info "*.csv" --quiet

datacleaner clean

Apply cleaning transformations to a file. You can use a saved profile or specify individual transformation flags. The cleaned data is written to the output file.

OptionDescription
--profile, -p NAMEUse a saved cleaning profile by name
--output, -o PATHOutput file path (required unless using --stdout)
--format FORMATOutput format: csv (default) or xlsx
--dry-runPreview what changes would be made without writing any files
--jsonOutput results as JSON for CI/CD integration
--quiet, -qSuppress non-essential output messages
--stdinRead CSV data from standard input instead of a file
--stdoutWrite cleaned CSV data to standard output instead of a file
--trim / --no-trimEnable or disable whitespace trimming
--normalize-nulls / --no-normalize-nullsEnable or disable null token normalization
--normalize-headers / --no-normalize-headersEnable or disable header cleaning
--remove-empty / --no-remove-emptyEnable or disable empty row removal
--normalize-dates / --no-normalize-datesEnable or disable date conversion to ISO format
--normalize-numeric / --no-normalize-numericEnable or disable numeric format standardization
 
# Clean using a saved profile
datacleaner clean data.csv --profile monthly --output cleaned.csv

# Manual options: trim + normalize nulls only
datacleaner clean data.csv --trim --normalize-nulls -o output.csv

# Preview changes without writing anything
datacleaner clean data.csv --dry-run

# Pipe from stdin to stdout
cat data.csv | datacleaner clean --stdin --stdout > cleaned.csv

# JSON output for CI/CD pipelines
datacleaner clean data.csv --json > results.json

datacleaner dedupe

Remove duplicate rows from a file. You can match on all columns or specify key columns for targeted deduplication.

OptionDescription
--columns, -c COLSComma-separated list of key columns to match on (omit for whole-row matching)
--keep STRATEGYWhich duplicate to keep: first (default), last, or most_complete
--output, -o PATHOutput file path for the deduplicated data
--dry-runShow which rows would be removed without writing
--jsonJSON output with duplicate counts and details
--quiet, -qMinimal output
 
# Remove exact whole-row duplicates
datacleaner dedupe data.csv -o deduped.csv

# Deduplicate by email column, keep first
datacleaner dedupe data.csv --columns email -o unique_emails.csv

# Keep last occurrence (most recent)
datacleaner dedupe data.csv --columns id --keep last -o latest.csv

# Keep most complete row (fewest nulls)
datacleaner dedupe data.csv --columns id --keep most_complete -o best.csv

# Preview without writing
datacleaner dedupe data.csv --dry-run

datacleaner validate

Run validation rules against a file and get a pass/fail report. Returns exit code 0 on success and exit code 2 on failure, making it ideal for CI/CD pipelines.

OptionDescription
--required COLSComma-separated list of columns that must exist in the file
--non-null COLSComma-separated list of columns that must have no null values
--email COLColumn name to validate as email format (RFC-5322)
--date COLColumn name to validate as parseable date format
--numeric COLColumn name to validate as numeric values only
--regex PATTERN COLValidate column values against a custom regular expression
--unique COLEnsure all values in the column are unique (no duplicates)
--in-list VALUES COLRestrict column to a whitelist of allowed values
--jsonJSON output with detailed validation results

# Check required columns exist
datacleaner validate data.csv --required name,email,id

# Validate email format
datacleaner validate customers.csv --email email_col

# Multiple validation rules at once
datacleaner validate data.csv --non-null id --numeric amount --date date_col

# Regex validation for phone numbers
datacleaner validate data.csv --regex "^\d{10}$" phone_col

# Generate report file
datacleaner validate data.csv --required id --report results.json

# Use in CI/CD (exits with code 2 on failure)
datacleaner validate data.csv --required id --non-null email && echo "PASS" || echo "FAIL"

datacleaner batch

Process multiple files at once using glob patterns. Supports parallel processing with configurable worker counts for maximum throughput on multi-core systems.

OptionDescription
clean / dedupe / validate / exportThe batch operation to perform (subcommand)
PATTERNGlob pattern matching files to process (e.g., "data/*.csv")
--output, -o DIROutput directory for processed files (required)
--profile, -p NAMECleaning profile to apply to all files

datacleaner batch clean "data/*.csv" --output cleaned/ --profile monthly -j 4

# Batch clean including subdirectories
datacleaner batch clean "data/**/*.xlsx" -o cleaned/ -j 4

# Skip errors and continue
datacleaner batch clean "*.csv" -o out/ --continue-on-error

# Batch deduplicate by email
datacleaner batch dedupe "inputs/*.csv" --output deduped/ --columns email

# JSON results for reporting
datacleaner batch clean "*.csv" -o out/ --json > batch_results.json

datacleaner watch

Monitor a folder for new files and automatically process them using your cleaning profile. This is the killer automation feature — set it up once and DataCleaner processes files as they arrive with zero manual intervention. Runs continuously until interrupted with Ctrl+C.

OptionDefaultDescription
WATCH_DIRRequiredThe directory to monitor for new files
--output, -o DIRRequiredDirectory where cleaned files are saved
--profile, -p NAMEdefaultCleaning profile to apply to incoming files
--archive DIRNoneMove original files to this folder after processing
--interval SECS30How often to poll the watch directory for new files (in seconds)
--patterns PATTERNS*.csvComma-separated file patterns to match (e.g., *.csv,*.xlsx)
--jsonOffOutput processing events as JSON (useful for logging)
--quiet, -qOffMinimal output
 
# Basic folder watching
datacleaner watch ./inbox --output ./processed --profile auto_clean

# Watch with archive (moves originals after processing)
datacleaner watch ./inbox --output ./cleaned --archive ./archive --profile default

# Custom interval (check every 60 seconds) with multiple patterns
datacleaner watch ./data --output ./out --interval 60 --patterns "*.csv,*.xlsx"

# JSON logging for monitoring systems
datacleaner watch ./input --output ./output --json > watch.log
How it works: DataCleaner polls the watch directory every --interval seconds (default: 30). When a new file matching the specified pattern is detected, it waits 2 seconds (debounce) to ensure the file has finished being written, then processes it using the specified profile and saves the output to the output directory. If --archive is set, the original file is moved to the archive folder after successful processing.

Pipes & Automation

DataCleaner supports Unix-style piping via --stdin and --stdout flags, making it composable with other command-line tools. Chain multiple operations together for powerful data pipelines.

Pipeline Examples
# Read from stdin, write to stdout
cat input.csv | datacleaner clean --stdin --stdout > output.csv

# Chain clean + sort
cat messy.csv | datacleaner clean --stdin --stdout | sort > sorted.csv

# Multi-stage pipeline: clean, then dedupe
cat data.csv \
  | datacleaner clean --stdin --profile monthly --stdout \
  | datacleaner dedupe --stdin --columns email --stdout \
  > final.csv

# Generate SQL and pipe directly to sqlcmd
cat data.csv \
  | datacleaner export --stdin --format sql --stdout \
  | sqlcmd -S SERVER -d DATABASE
Automation Recipes
# Complete workflow: check, clean, validate, export
datacleaner info data.csv --profile
datacleaner clean data.csv --dry-run
datacleaner clean data.csv -o cleaned.csv --profile monthly
datacleaner validate cleaned.csv --required id,email
datacleaner export cleaned.csv -o final.xlsx --format xlsx

# Windows Task Scheduler script (run nightly)
datacleaner batch clean "C:\data\raw\*.csv" -o "C:\data\cleaned" -j 4 --profile nightly
datacleaner batch validate "C:\data\cleaned\*.csv" --non-null id
datacleaner batch export "C:\data\cleaned\*.csv" -o "C:\data\sql" --format sql

Performance Tips

  • 1.For files over 100 MB: Use the CLI instead of the GUI. The CLI processes data without rendering a preview table, which saves significant memory and processing time.
  • 2.For batch processing: Use the --parallel flag with datacleaner batch to process multiple files simultaneously. Set the worker count to your CPU core count for maximum throughput.
  • 3.For very large files: Split them into smaller chunks before processing. DataCleaner's batch mode can then process each chunk in parallel and you can merge the results afterward.
  • 4.Memory management: The undo history is automatically reduced for large files. For files over 250 MB, only 1 undo step is preserved to conserve memory.

Troubleshooting & FAQ

Common issues and their solutions. If your issue is not listed here, please open an issue on GitHub.

Check the file format: DataCleaner supports CSV, TSV, TXT, and XLSX files only. Other formats like XLS (legacy Excel), ODS, or JSON are not supported.

Check if the file is locked: If the file is open in another application (Excel, Notepad++, etc.), close it first. Some applications lock files while they are open.

Check file size: Files larger than 500 MB are rejected. Use a tool like PowerShell or a text editor to split the file into smaller chunks.

Check encoding: If you see garbled characters after import, the encoding was likely detected incorrectly. Try re-saving the file as UTF-8 in Notepad or another editor, or manually select the encoding in the import dialog.

Use the CLI: For files over 100 MB, the command-line interface processes data without rendering the preview table, saving significant memory and time.

Split your file: Divide large files into smaller chunks. DataCleaner's batch mode can process them in parallel with the --parallel flag.

Close other applications: Large file processing is memory-intensive. Close unnecessary applications to free up RAM.

Use streaming: For very large files, use datacleaner clean --stdin --stdout for streaming processing that doesn't load the entire file into memory at once.

Check for invisible characters: Cells may contain hidden whitespace, zero-width characters, or non-breaking spaces that look correct visually but fail validation. Run the "Trim whitespace" transformation first.

Check null tokens: A cell containing "N/A" is technically not empty, but it may not pass a "non-null" validation until you normalize null tokens first.

Review the validation report: Click on the failed rule to see exactly which rows failed and why. The report shows sample values that did not pass.

Adjust thresholds: Date and numeric confidence thresholds may be too strict. Try lowering them from 90% to 80% in your profile settings.

Verify the key file location: Your license key should be placed at ~/.config/datacleaner/license.key. On Windows, this translates to C:\Users\YOUR_USERNAME\.config\datacleaner\license.key.

Check the key format: Open the key file in a text editor and verify it contains a single block of base64-encoded text with no extra spaces or line breaks.

Re-activate: Try re-activating through Help > Activate License in the application menu.

Machine limit: If you've exceeded the machine limit for your license tier, deactivate on another machine first or contact support for assistance.

Check the ambiguity threshold: Values like "1.234" can be ambiguous (is it 1234 or 1.234?). If the threshold is set to 90%, at least 90% of values in the column must follow the same pattern for conversion.

Use the Bank Export profile: The bundled "bank_export" profile is pre-configured for European financial data with appropriate numeric handling settings.

Set per-column format: In the Auto Format tab, you can override the format detection for individual columns to explicitly specify European decimal format.

@echo off
